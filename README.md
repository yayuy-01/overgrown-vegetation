# Overgrown Vegetation

「異常繁殖を繰り返す寄生植物」が世界を侵食していく Minecraft の MOD です。
胞子が風に乗って広がり、森が地形を飲み込み、森の意思が Mob の軍勢を送り込んできます。
サバイバルの進行そのものを変えるコンテンツを追加します。

> **0.2.0-alpha(アルファ版)です。** 遊べる形になっていますが、数値の調整や仕上げは途中です。
> 仕様は今後変わります。古いワールドとの互換は保証しません。

## 特徴

- **胞子と侵食** — 汚染の発生源と森から胞子が生まれ、世界に 1 つの卓越風で運ばれて降り積もり、芽吹いて「過繁茂」の森になります。崖や洞窟、水辺にもそれぞれの生え方があります。
- **フェーズ進行** — ワールド 3 日目以降、地割れとともに侵食が始まります(F1)。森の広さや器官の数で世界の段階が進み、出てくる敵や襲撃が変わります(このアルファ版は F7 まで)。
- **森の知性** — 森は巨大樹ごとの「樹域」に分かれ、バイオマスを使って部隊を作り、守り・広げ・狩り・襲撃に送ります。偵察に見つかったプレイヤーは狩られ、拠点には襲撃が来ます。
- **寄生された Mob と森の生き物** — バニラの動物や Mob が寄生され、進化し、根付き、苗床になります。森の中には植物の Mob と、石炭紀の生き物を思わせる環境生物が暮らしています。
- **籠城と遠征** — 胞子の暴露量と疲労を管理しながら、拠点の部屋を換気機とフィルターで守り、汚れた装備を洗い場で落とします。地脈の力で動く機械と導晶の道具・防具で、汚染地帯へ遠征します。
- **押し返す手段** — 灰と石灰の帯、地脈の杭、換気機などで侵食を食い止められます。留守の間も、電力とフィルターが続く限り拠点を守ります。

## 導入方法

1. 遊ぶ Minecraft の版に合わせて、[NeoForge](https://neoforged.net/)(1.21.1)または [Forge](https://files.minecraftforge.net/)(1.20.1)を導入する
2. 前提 MOD の [GeckoLib](https://modrinth.com/mod/geckolib) を `mods` フォルダに入れる
3. 本 MOD の jar(遊ぶ版に合った物)を `mods` フォルダに入れる

### 描画の MOD について

- **1.21.1**: [Sodium](https://modrinth.com/mod/sodium) の導入を勧めます(必須ではありません)。見た目の調整と確認は Sodium を入れた環境で行っています。
- **1.20.1**: Embeddium・Oculus と一緒に動きます。そのときは、この MOD の地形のシェーダーを使わず、バニラに近い見た目になります。
- [Distant Horizons](https://modrinth.com/mod/distanthorizons) と一緒に動きます。
- 重いときは、ビデオ設定(Sodium を入れているときは Sodium の設定の画面の「Overgrown Vegetation」のページ)で、この MOD の演出の質を **高・中・低・なし** から選べます。「なし」は見た目だけの演出を全部切ります。

## 実験的要素

まだ仕上がっていない要素は「実験的要素」として、既定ではオフになっています。ワールドの設定の画面で 1 つずつオンにできます。

- ネザーの新しい侵食
- ワールドイベント(空や海に起きる大きな出来事)
- 蠢く壁(洞窟を塞いで追ってくる森)
- 研究(研究台で素材を調べて作り方を開く。オフのときは、研究で開く作り方は最初から作れます)
- 防具の装飾(口覆いの布は、オフでも作業台で兜と合わせて付けられます)

## コマンド

`/ov` の下にあります(OP 専用)。主な物:

| コマンド | 説明 |
| --- | --- |
| `/ov phase` | 今のフェーズの確認・変更 |
| `/ov experimental` | 実験的要素の切り替え |

## ソースからビルドする

> **このリポジトリには素材(テクスチャ・モデル・アニメーション・効果音)が含まれていません。**
> コードはビルドできますが、できた jar はブロックやアイテムの表示が欠け、Mob は正常に描画されません。
> 遊ぶ場合は作者が配布する jar を使ってください。

- `main` ブランチ: Minecraft 1.21.1 / NeoForge(JDK 21)
- `1.20.1` ブランチ: Minecraft 1.20.1 / Forge(JDK 17)

```
gradlew.bat build        # build/libs/ に jar を出力
```

初回の Gradle 同期は Minecraft の展開とマッピング適用のため 5〜15 分かかります。
